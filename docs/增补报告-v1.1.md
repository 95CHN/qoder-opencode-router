## 3. 需求二：不可信原则与中断处置

### 3.1 失败分类（脚本输出 `FAILURE_CLASS / RETRYABLE / ACTION`）

13 类：`quota-daily`、`rate-limit`、`geo-restricted`、`model-not-found`、`context-overflow`、`auth`、`provider-init`、`network`、`server-error`、`timeout`、`out-of-scope`、`stale-report`、`no-report`。

识别来源：事件流的 `error` 事件（如 `provider.no-route`、`provider.auth`）、stderr、工具错误、退出码、报告新鲜度、写入路径越界。

### 3.2 三选一决策树（写进 SKILL.md，详表在 failure-playbook.md）

| 情况 | 决策 |
|---|---|
| `quota-daily`（账号级每日额度耗尽）、`auth` | 剩余量小且无需用户拍板 → **①我来干完**；否则 → **②停止上报**。**换免费模型通常无效** |
| `geo-restricted`、`model-not-found`、`rate-limit`、`server-error`、`network` | **③换免费模型**：`fallback --try` 依次试最多 3 个，新会话 |
| `context-overflow`、`timeout`、`out-of-scope`、`stale-report` | 换模型无用：拆任务/精简契约/修路径后重派；不行再转①或② |

**关键判断依据**（来自社区实测）：每日免费消息额度是**账号级**的，耗尽时所有 `*-free` 模型返回同一限额错误——所以"换模型"不是万能对策，脚本对 `quota-daily` 会直接提示别刷请求。

硬上限：同模型退避重试 ≤1 次、换模型 ≤3 个、返工 ≤2 轮，超限即停。

### 3.3 接管协议（选①时保证台账不断链）

`takeover --task X --note "原因"` 标记执行者 → Qoder 亲自补完 → **由 Qoder 写 report.md**（保留 TASK_ID、ROUND 递增、加 `EXECUTOR: qoder-takeover`、追加接管记录写明中断类别/opencode 已完成部分/接管做了什么/复验证据，不删原有真实内容）→ `verify` + 语义验收 → 汇报时**分清外包完成与接管完成**。

### 3.4 模型健康档案

新增 `model-health.json`（工作区根目录），记录每个模型最近一次结果与时间。`fallback` 据此**自动跳过** `geo-restricted / auth / model-not-found` 的模型，并优先选已验证 `ok` 的。台账 INDEX.md 的模型列现在显示完整档位/模型链（含失败尝试），可溯源。

## 4. 官方文档调研结论

- 官方 troubleshooting 文档给出：日志目录（Windows `%USERPROFILE%\.local\share\opencode\log`）、`--log-level DEBUG`、`--print-logs`，以及 `ProviderModelNotFoundError`、`ProviderInitError` 两类错误。
- **官方文档未给出限额/配额的具体错误串**。真实错误串来自社区 issue：`You've used today's free messages. They reset at …`、`Free usage limit reached. Subscribe to OpenCode Go to keep going`、`Rate limit exceeded`。
- 限额与账单问题官方引导走**账号支持渠道**（issue 中给出 help@anoma.ly），而非 GitHub issue。
- 重要提醒：网关可能把 403、余额不足、上游超时统一改写成 `Rate limit exceeded`，所以"稍后重试"只适合短时速率限制；等待后仍 429 应查额度。
- 排错记录四项：HTTP 状态码、供应商/网关 URL、错误响应体、是否有 `Retry-After`；**不要外泄 API Key / Authorization 头 / auth.json**。

以上均已写进快照与手册，并标注哪些是官方文档、哪些是社区实测。

## 6. 本轮修掉的问题

1. **错误事件未解析**：opencode 把失败放在事件流 `{"type":"error","error":{…}}` 里，stderr 为空。原实现只看 stderr → 真实报错被归为 unknown-error。已补解析。
2. **分类大小写 bug**：haystack 转小写后 `ProviderModelNotFoundError` 匹配不上。已加 `re.I`。
3. **旧报告冒充交工**：失败轮次里上一轮的 report.md 仍在，会被误判成功。已加 mtime 新鲜度判定 → `stale-report`。
4. **地域限制未覆盖**：实测发现后新增 `geo-restricted` 类与健康档案跳过机制。
